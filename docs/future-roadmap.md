# Future roadmap

1. Add a FastAPI/PostGIS service, Alembic migrations, Redis/RQ worker and signed object storage.
2. Decode and align GeoTIFF imagery with Rasterio, cloud masks, CRS-aware metadata entry and quality reports.
3. Add MapLibre/Leaflet basemaps, live GeoJSON layer loading, imagery swipe and map snapshot persistence.
4. Connect legally usable Sentinel/Landsat or organization-provided imagery with provider licensing and rate limits.
5. Add calibrated U-Net/Siamese/Random Forest adapters with versioned model registry and independent evaluation.
6. Add wildfire, landslide, cyclone and vegetation-damage adapters using the same analysis, scoring, evidence and review contracts.
7. Add real authentication, role permissions, audit review workflows, retention policies, monitoring, alerting and operational incident integrations.
8. Add human-in-the-loop feedback to recalibrate uncertainty, report false positives and improve priority weights.
